## Count summary

- Controlled baseline Seed: **15 Firestore academic documents** (2 universities + 3 colleges + 4 departments + 6 subjects).
- Real UI workflow business documents: **20 planned** (6 user profiles, 2 recruiter requests, 3 positions, 3 applications, 2 documents, 3 interviews, 1 rating), plus **6 Firebase Auth identities**, notifications, and audit records generated by workflows.
- No document ID, Auth UID, password, file content, or Production write is created by this manifest.

## Required execution manifest fields

| Field | Rule |
|---|---|
| `seedBatchId` | generated only at execution; not hard-coded here |
| alias | stable human alias such as U1/C1/APP-01 |
| collection / UID | actual generated value recorded locally in sensitive execution manifest |
| creation method | `baseline-seed`, `ui-workflow`, or `automatic-event` |
| dependency aliases | parent/owner/event prerequisites |
| cleanup eligibility | exact manifest entry only; never broad production query |
| protected | true only for Super Admin; never cleanup eligible |
