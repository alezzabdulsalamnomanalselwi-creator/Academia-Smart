# دليل المستخدم

## إعداد العرض

استخدم زر اللغة للتبديل بين العربية والإنجليزية، وزر المظهر لاختيار Light أو Dark أو System. تتغير النصوص الثابتة واتجاه الواجهة تلقائيًا؛ تبقى أسماء المستخدمين والكيانات كما أدخلت في النظام.

## Super Admin

1. افتح **لوحة إدارة النظام** لمراجعة مؤشرات المستخدمين والحالة والعمليات الأخيرة.
2. من **الحسابات والصلاحيات** راجع المستخدمين، أنشئ مديرًا محدود الصلاحيات عند الحاجة، أو حدّث صلاحياته. حساب Super Admin محمي.
3. من تبويبات **الجامعات والكليات والأقسام والمواد** أدر التسلسل الأكاديمي. لا تحذف جهة مرتبطة؛ استخدم الإيقاف عندما يلزم.
4. راجع **طلبات الانضمام** لقبول أو رفض طلبات مسؤولي التوظيف عبر المسار المعتمد.
5. استخدم **التقرير الأكاديمي** للطباعة أو الحفظ PDF، و**سجل العمليات** للمراجعة الإدارية.
6. يمكن حظر/فك حظر حسابات الاختبار المسموح بها؛ لا تغيّر حساب Super Admin المحمي أثناء العرض.

## Limited Admin

تتحدد التبويبات المتاحة بالصلاحيات المخزنة للحساب. حساب العرض المحدود يملك Reports وAudit فقط؛ لا يستطيع إدارة الحسابات أو البيانات الأكاديمية.

## Recruiter

1. استخدم **نشر وظيفة** لإنشاء إعلان مرتبط بالجامعة/الكلية/القسم/المادة.
2. راجع الطلبات من **عرض الطلبات** وحدّث حالتها ضمن الوظائف التي يملكها الحساب فقط.
3. من **مراجعة المستندات** اعرض المستند المحمي وسجل قرار القبول/الرفض وملاحظة المراجع.
4. أدر المقابلات: schedule, reschedule, complete, cancel, أو no-show حسب الحالة.
5. أرسل التقييمات بعد المقابلة، واستخدم **Candidate Ranking / Compare** كمساعدة تفسيرية لا كقرار توظيف تلقائي.
6. استخدم Smart Assistant للحصول على اقتراح مرتبط بالدور والصفحة؛ يعمل Smart Local عند عدم توفر Cloud AI.

## Lecturer

1. أكمل الملف الشخصي والمؤهلات والخبرات والمهارات.
2. من **استعراض الوظائف** افتح الوظيفة المناسبة وقدّم طلبًا واحدًا فقط لكل وظيفة.
3. ارفع المستندات المطلوبة من صفحة المستندات؛ يسمح النظام بالوصول المحمي للمالك والمراجع المعين فقط.
4. تابع الطلبات والمقابلات والتقييمات والإشعارات من اللوحة.
5. افتح الإشعارات للوصول إلى الكيان ذي الصلة. حافظ على وجود ملف CV صالح قبل التقديم إذا كان ذلك مطلوبًا.
6. استخدم Smart Assistant للإرشاد؛ لا يغير المساعد أي قرار أو بيانات بنفسه.

## ملاحظات عامة

- يجب تسجيل الدخول بحساب الدور المناسب.
- 401 يعني جلسة/رمز دخول غير صالح؛ 403 يعني أن الحساب لا يملك التفويض؛ 404 يعني أن المرجع أو الملف غير موجود.
- لا تستخدم بيانات شخصية حقيقية في بيئة العرض.
