# سيناريو عرض التخرج (8–12 دقيقة)

## قبل المناقشة

- فك ضغط الحزمة مسبقًا، ثم انقر مرتين على `START-ACADEMIA-SMART.cmd` وانتظر حتى دقيقتين في أول تشغيل لفتح صفحة الدخول؛ لا تحتاج نسخ `.env` يدويًا لأن الإعداد العام للواجهة ينشئ `.env.local` تلقائيًا.
- شغّل `CHECK-ACADEMIA-SMART.cmd` على جهاز العرض قبل الموعد إن أمكن، واستخدم `STOP-ACADEMIA-SMART.cmd` فقط بعد انتهاء العرض.
- شغّل التطبيق وLocal File API مسبقًا وتحقق من المنفذين 3015 و5050.
- سجّل الدخول بالحسابات التجريبية قبل بدء العرض عند الحاجة.
- تحقق من الإنترنت، لكن لا تعتمد عليه: Smart Local fallback يعمل بدون Cloud AI.
- احتفظ بـRelease ZIP محليًا، ولا تشغّل `npm install` أو تعدل Production أثناء العرض.
- إذا انتهت جلسة المتصفح، أعد تسجيل الدخول فقط؛ إذا انقطع الإنترنت، اعرض الواجهة والبيانات المحملة وSmart Local؛ إذا تعطل Cloud AI، أوضح أن المساعد يتحول محليًا ولا يتخذ قرارات توظيف.

## التسلسل المقترح

1. **تسجيل الدخول (30ث):** «النظام يفصل الصلاحيات من أول لحظة حسب نوع الحساب.»
2. **Super Admin overview (45ث):** «هنا مؤشرات المنصة والحسابات والحالة وسجل الأنشطة؛ حساب المدير الأعلى محمي.»
3. **Academic hierarchy (45ث):** «نبدأ من الجامعة ثم الكلية والقسم والمادة، وتتحقق العلاقات قبل الحذف.»
4. **Recruiter workflow (45ث):** «مسؤول التوظيف ينشر وظائف مرتبطة بالهيكل الأكاديمي ويشاهد طلباته فقط.»
5. **JOB-01 وApplication01 (60ث):** «هذه الوظيفة المنشورة وهذا طلب المحاضر؛ تتغير حالته ضمن مسار العمل.»
6. **Document review (45ث):** «عرض المستند محمي بالهوية والملكية؛ قرار المراجعة مع ملاحظة يصل للمحاضر.»
7. **Interview (45ث):** «ننشئ أو نكمل مقابلة ونستخدم الرابط أو الموقع بحسب النوع.»
8. **Rating (45ث):** «بعد المقابلة يرسل المسؤول تقييمًا موثقًا مرتبطًا بالطلب.»
9. **Notifications/deep links (30ث):** «الإشعار يحمل المستلم والهدف ورابطًا مباشرًا، مع حالة read/unread.»
10. **Candidate ranking/compare (60ث):** «الترتيب تفسيري ومساعد فقط: يعرض نقاط القوة والفجوات ولا يقرر التوظيف تلقائيًا.»
11. **Smart Assistant (45ث):** «المساعد يعرف الدور والصفحة؛ عند عدم توفر Cloud AI يستخدم Smart Local.»
12. **اللغة والمظهر (30ث):** «نبدل العربية/الإنجليزية وRTL/LTR ثم Dark/System دون تغيير البيانات أو الصلاحيات.»
